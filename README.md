# Portfólio Web – Desenvolvimento Web

Projeto desenvolvido como trabalho da disciplina de Desenvolvimento Web do curso de Ciência da Computação da UNINTER.

## 📌 Objetivo

O objetivo da atividade foi desenvolver um site de portfólio pessoal utilizando apenas tecnologias básicas da web:

- HTML
- CSS
- JavaScript

Sem uso de frameworks ou bibliotecas externas.

## 🧠 Proposta

Criar um site estático que apresente:

- Informações pessoais
- Experiência ou trabalhos realizados
- Formas de contato

O foco principal foi aplicar conceitos fundamentais de desenvolvimento front-end.

## 🛠️ Tecnologias Utilizadas

- HTML5 → estrutura da página
- CSS3 → estilização e layout
- JavaScript → interações e validações

## 🎨 Funcionalidades

- Layout responsivo básico
- Alternância entre modo claro e modo escuro
- Menu de navegação entre seções
- Formulário de contato com validação
- Estilização personalizada (incluindo scrollbar e efeitos visuais)

## 🚀 Como Executar

1. Baixe ou clone o repositório
2. Abra o arquivo `porfolio.html` em qualquer navegador

Não é necessário servidor.
